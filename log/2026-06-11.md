## In my own words
A C program is like one training session at the gym. Loading the equipment rack is the include line that brings in the printing tools. The main workout is the main function, which is where the program always starts when you run it. Each finished exercise is a statement that ends in a semicolon, which is like racking the weight before the next set. The newline marker steps back cleanly so the next print starts fresh. Signing the logbook at the end is return zero, which tells the operating system the session went well. The compiler is the coach who has to approve the plan before I am allowed to train, which is why code has to compile before it can run.
