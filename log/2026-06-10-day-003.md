## In my own words (the recall rep)
- **Hex = binary in a readable costume.** 1 hex digit = exactly 4 bits because 16 = 2⁴.
  Converting is pure substitution by nibbles, no arithmetic. That's why addresses/registers
  are always shown in hex.
- **Two's complement** stores negatives so that *normal binary addition just works*. Negate
  by flip-all-bits + 1; the reason it works is flip(x) = (2ⁿ−1)−x, so flip+1 = 2ⁿ−x, which
  overflows to 0 when added to x. The MSB carries negative weight (−8 in 4-bit). Range is
  −8..+7 (one extra negative because there's only one zero).
- **The payoff:** a CPU has no subtractor. `a − b` = `a + negate(b)`, same adder, carry falls
  off the end. One adder does +, −, and the basis of ×/÷.
- **Habit learned:** after negating, *read the result back* via place values to self-check.
