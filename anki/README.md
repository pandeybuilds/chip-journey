# Anki — how I refuse to forget

This is the single fix for "I forget everything." You are not re-learning each day —
you are refusing to let it leak out. 10 minutes, every day, before anything else.

## Setup (once)

1. Install Anki (free desktop app; AnkiWeb sync to phone for reviews anywhere).
2. Create a deck called `chip-journey`.
3. Import [`starter-cards.tsv`](starter-cards.tsv): *File → Import*, set field separator to
   **Tab**, map Field 1 → Front, Field 2 → Back.
4. Do your due cards every weekday morning. That's it.

## The card-making rules (most people make bad cards — don't)

- **One fact per card.** If the answer has two parts, make two cards.
- **Test recall, not recognition.** Front asks a question; back is the answer. Never "read this paragraph."
- **Make them yourself.** Writing the card is half the learning. Add cards every weekend from the week's work.
- **Include "why," not just "what."** A card that asks *why* two's-complement makes subtraction free beats one that just defines it.
- **Code/derivation cards:** Front = "derive X" or "what does this snippet output?"; Back = the worked answer.

## Cadence

- **Daily:** review due cards (10 min).
- **Weekend:** add 5–15 new cards from the week. Quality over quantity.

If a card keeps failing, it's a bad card or a real gap — rewrite it or go build the thing.
